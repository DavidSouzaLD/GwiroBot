Busca automática

Estes tempos valem para o grupo aberto na barra. A busca automática só acontece nos grupos ativados, cada um no próprio ritmo.

Ao abrir o Ogwiro, só este grupo começa a busca na hora, se estiver ativado. Os outros grupos não mudam.

A primeira busca deste grupo acontece na hora. Desligado, o bot espera o intervalo de cada vitrine.

300 segundos são 5 minutos. O mínimo é 30.
